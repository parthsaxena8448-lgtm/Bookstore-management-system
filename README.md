# Bookstore Management System

A full-stack bookstore management system built using React,
Node.js, Express.js and MongoDB.

## Features

### Customer
- Register and login
- Browse books
- Search books
- Filter books
- Pagination
- View book details
- Add books to cart
- Checkout
- View orders

### Admin
- Admin authentication
- Add books
- Edit books
- Delete books
- Manage inventory
- View customer orders
- Update order status

## Technologies

### Frontend
- React
- React Router
- Axios
- Bootstrap
- Bootstrap Icons

### Backend
- Node.js
- Express.js
- JWT
- bcryptjs

### Database
- MongoDB
- Mongoose
